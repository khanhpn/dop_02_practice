# DOP-C02 Study Lab Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for app tasks; content research is delegated as bounded independent domain packages under Sites workflow.

**Goal:** Build the full Vietnamese DOP-C02 study site and verified GitHub Pages automation.

**Architecture:** Static React SPA with MUI, typed authored domain packages, local persistence, hash navigation. No automated test suite.

**Tech Stack:** React, TypeScript, MUI, Vite, GitHub Actions.

**Spec:** docs/superpowers/specs/2026-10-19-dop-study-design.md

## Global Constraints

- 72 lessons across 6 official domains and 19 tasks; >=20 original EN/VI practice questions per lesson.
- Lesson and option rationale in Vietnamese; CloudFormation first; Terraform comparison.
- Local browser data, export/import; GitHub Pages on master; tags v0.0, v0.1, ...
- No claimed deployment before actual GitHub result.

## Review Focus

- Multi-select must match exactly and count unselected questions incorrect.
- Imported data must reject malformed attempts before replacing good local data.
- Hash deep links with section query must scroll to actual section.
- Reruns must not create a second tag for the same commit; tag sort must be numeric (v0.10 > v0.9).
- Content minimums must not hide duplicate/padded questions or unsupported AWS claims.

### Task 1: Authored curriculum and domain research

**Files:** src/content/types.ts, domain1.ts..domain6.ts, index.ts.
**Interfaces:** exports lessons: Lesson[], domains: Domain[], chapters: Chapter[].

- [ ] Research official guide and author 72 lessons + question/lab content.

### Task 2: Quiz, storage, planner and tag logic

**Files:** src/core/\*.ts, scripts/version.mjs.
**Interfaces:** gradeQuestion(correct: string[], selected: string[]): boolean; selectMock(questions, random): Question[]; parseBackup(text): StudyState; nextTag(tags): string.

- [ ] Implement core modules; verify with `pnpm check`, not a test suite.

### Task 3: Study UI

**Files:** src/App.tsx, src/theme.ts, src/components/_, src/pages/_, src/styles.css.
**Interfaces:** study context state plus update function; router paths /, /curriculum, /lesson/:id, /practice, /plan, /settings.

- [ ] Build responsive MUI shell, dashboard and lesson experience.
- [ ] Build quiz with EN/VI toggle and per-option VI rationale links, mock and wrong answer review.
- [ ] Build planner, notes/bookmarks, settings and backup workflow.
- [ ] Run browser checks of real user flows and fix observed failures.

### Task 4: CI, documentation and final verification

**Files:** .github/workflows/pages.yml, README.md, scripts/version.mjs.

- [ ] Implement master verify → tag → Pages deploy; PR verify only.
- [ ] Run `pnpm check`, production build, and content audit. Do not run Vitest or Playwright.
- [ ] Review implementation against spec and record real counts/verification limits.
